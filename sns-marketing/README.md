# 같이가게 (해커톤 MVP)

소상공인 사장님이 가게 정보를 한 번 등록해 두면, **새 게시물**을 누를 때마다 AI가 문구·홍보 카드·사진 보정을 만들어 주고, 확인 후 **인스타그램·페이스북·스레드에 동시에** 올리고 관리하는 웹서비스입니다.

## 실행

`start.bat` 더블클릭 (처음엔 Gemini API 키를 물어보고 패키지를 설치해요) → 브라우저에서 http://localhost:3000

- Gemini 무료 키: https://aistudio.google.com/apikey
- 키가 없거나 AI 호출이 실패하면 예시 결과로 대신 보여줘서 시연이 멈추지 않아요 (`FALLBACK_TO_MOCK=true`)

## 흐름

1. **가게 정보** 등록: 이름·업종·주소·상품/서비스·기타 → AI가 문구 쓸 때 참고하는 고객 정보
2. **＋ 새 게시물**: 무엇을 홍보할지(상품 버튼 또는 직접 입력), 강조할 내용, 분위기, 참고 사진(카메라/앨범)
   - "뭘 올릴지 모르겠어요"를 누르면 AI가 아이디어 3개 추천
3. AI가 만들어 주는 것
   - 플랫폼별 문구 3개 (인스타: 해시태그 포함 / 페이스북: 정보 위주 / 스레드: 500자·해시태그 1개) — Gemini가 참고 사진을 직접 보고 씀
   - 사진 자동 보정 (밝기 범위·채도·선명도) + 보정 프리셋: 밝게 / 따뜻하게 / 선명하게
   - 홍보 카드 이미지 (사진+아래 글 / 포스터형 / 글자만, 색상 선택, 제목 수정)
   - ✨ AI 이미지 그리기 / AI 보정 (Gemini 이미지 모델 — 무료 키에서는 막혀 있을 수 있음)
4. **이렇게 올릴까요?** 화면: 플랫폼별 미리보기, 사진 선택·순서(번호), 문구 수정(자동 저장), 올릴 곳 체크
5. **동시에 올리기** → 결과 표시
6. **내 게시물**: 임시저장/게시됨 필터, 게시 현황, 반응 새로고침(좋아요·댓글 등), SNS에서 삭제, 실패한 곳 다시 올리기

자동 보정과 홍보 카드는 브라우저에서 직접 만들어서 비용이 들지 않아요.

## 실제 구현 vs 목업 (현재 상태)

> 기준일 2026-11-19. "검증"은 실제 외부 서비스로 확인했는지를 뜻해요. 외부 API 연동은 개발 환경에서 Gemini·Meta API를 흉내 낸 **가짜(mock) 서버**로 전체 흐름을 테스트했고, 실제 계정으로는 아직 확인하지 않았어요.

### ✅ 실제로 동작하는 기능 (외부 서비스 없이 완결)

| 기능 | 설명 |
|---|---|
| 가게 정보 등록·수정 | 이름·업종·주소·상품/서비스·기타 저장 (`data/db.json`) |
| 게시물 생성·임시저장·목록·삭제 | 내 게시물 화면, 임시저장/게시됨 필터 |
| 사진 첨부 | 앨범 선택, 폰 카메라 앱, PC 웹캠 촬영 |
| 사진 규격 변환 | JPEG, 4:5~1.91:1 비율 자동 자르기, 긴 변 1440px (인스타 규격) |
| 사진 자동 보정 | 밝기 범위·감마·채도·색온도·선명도 (브라우저 canvas, 무료) — 자동/밝게/따뜻하게/선명하게 |
| 홍보 카드 이미지 | 사진+아래 글 / 포스터형 / 글자만, 색상·문구 수정 (브라우저 canvas, 무료) |
| 플랫폼별 미리보기·문구 편집 | 자동 저장, 글자 수 제한 표시, 스레드 해시태그 1개 자동 정리 |

### 🔌 실제 API 연동 코드 (구현 완료 · 실제 계정 검증 전)

| 기능 | 사용하는 API | 확인 상태 |
|---|---|---|
| AI 문구 생성 (참고 사진을 보고 작성) | Gemini `generateContent` (gemini-2.5-flash, 이미지 입력) | mock 서버로 요청·응답 형식 확인 |
| AI 게시물 아이디어 3개 | Gemini | mock 서버로 확인 |
| AI 이미지 그리기 / AI 보정 | Gemini 이미지 모델 (`gemini-2.5-flash-image`) | mock 서버로 확인 · **무료 키에서는 막혀 있을 가능성이 높음** |
| 페이스북 페이지 게시 (글 / 사진 1장 / 여러 장) | Graph API `/{page}/feed`, `/{page}/photos` | mock 서버로 확인 |
| 인스타그램 게시 (사진 1장 / 캐러셀) | Instagram Content Publishing API | mock 서버로 확인 · 공개 주소(터널) 필요 |
| 스레드 게시 (글 / 사진 / 캐러셀) | Threads API | mock 서버로 확인 · 사진은 공개 주소 필요 |
| 게시물 삭제 | 페이스북·스레드 DELETE (인스타는 API 미지원 → 앱에서 직접) | mock 서버로 확인 |
| 반응 보기 (좋아요·댓글 등) | IG media 필드, FB reactions/comments, Threads insights | mock 서버로 확인 · 토큰 권한 필요 |
| 계정 연결 확인 | 각 API `/me`, `/{page}` 조회 | mock 서버로 확인 |

### 🧪 목업 / 데모용 (실제 서비스 전 교체 필요)

| 항목 | 지금 방식 | 실제 서비스라면 |
|---|---|---|
| AI 없을 때 결과 | API 키가 없거나 호출이 실패하면 `server/mock.js`의 **규칙 기반 예시 문구**로 대체 (화면에 "예시 문구" 표시) | 에러 안내 또는 재시도 |
| 로그인 | 없음. 브라우저 localStorage에 가게 ID만 저장 | 회원가입·로그인 |
| 데이터베이스 | JSON 파일 (`data/db.json`), 사진은 `data/uploads/` | SQLite/PostgreSQL + 클라우드 저장소 |
| SNS 계정 연결 | 사장님이 Meta 개발자 페이지에서 받은 **토큰을 직접 붙여넣기**, 서버 파일(`data/connections.json`)에 평문 저장 | OAuth 로그인 버튼 + 토큰 암호화 + 자동 갱신 |
| Meta 앱 | 개발 모드 → 앱에 등록된 **본인 계정에만** 게시 가능 | Meta 앱 심사 통과 후 공개 |
| 공개 주소 | cloudflared 임시 터널 (`tunnel.bat`) | 배포 서버 도메인 |
| 네이버 플레이스·블로그, 당근 | 공식 게시 API가 없어 미지원 (문구 복사로 대응) | — |
| 예약 게시, 릴스(영상), 결제 | 미구현 | — |

## 계정 연결

| 플랫폼 | 글만 | 사진 | 공개 주소 필요 | API 삭제 | 반응 보기 |
|---|---|---|---|---|---|
| 페이스북 페이지 | O | 1~10장 | X (파일 직접 업로드) | O | O (pages_read_engagement) |
| 인스타그램 (프로페셔널 계정) | X | 1~10장 (캐러셀) | O | X (앱에서 직접) | O |
| 스레드 | O (500자) | 1~10장 | 사진 있을 때만 O | O (threads_delete) | O (threads_manage_insights) |

**공개 주소**: 인스타그램·스레드는 Meta 서버가 사진을 URL로 가져가요. `start.bat`을 켠 상태에서 `tunnel.bat`을 실행하면 나오는 `https://….trycloudflare.com` 주소를 계정 연결 화면의 공개 주소 칸에 넣어 주세요. 터널이 켜져 있는 동안은 주소를 아는 사람 누구나 이 서비스에 접속할 수 있으니, 시연이 끝나면 터널 창을 닫아 주세요.

## 구조

```
server/
  index.js        API 라우트 (가게, 게시물, 사진, 생성, 게시, 관리, 계정 연결)
  db.js           JSON 파일 저장소 (data/db.json)
  llm.js          Gemini / Groq / mock 호출, 참고 사진 전달, AI 이미지
  prompts.js      게시물·아이디어 프롬프트와 JSON 형식
  mock.js         데모 모드 결과
  publish.js      Meta Graph API: 게시, 삭제, 반응, 연결 테스트
  connections.js  토큰 저장 (data/connections.json)
  setup-key.js    처음 실행 시 API 키 입력
public/
  app.js          화면
  imaging.js      사진 규격 변환·자동 보정·홍보 카드 (canvas)
```
