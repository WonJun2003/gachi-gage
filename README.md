# 같이가게 MVP

대학생과 소상공인을 연결하는 실무 프로젝트 플랫폼의 MVP예요.
Python(Flask)로 만들었고, 데이터는 이 폴더 안의 `data/gachi.db`(SQLite)에 저장돼요.

## 실행하기 (Windows)

1. Python이 없다면 https://www.python.org/downloads/ 에서 설치해요.
   설치 첫 화면에서 **"Add python.exe to PATH"**를 꼭 체크하세요.
2. 이 폴더의 **`run_windows.bat`**을 더블클릭해요.
   - 처음 한 번은 필요한 패키지를 설치하느라 1~2분 걸려요.
   - 브라우저가 열리면서 http://127.0.0.1:5000 이 나와요. 안 열리면 주소를 직접 입력하세요.
3. 끄려면 검은 창에서 `Ctrl + C`를 누르거나 창을 닫아요.

Mac/Linux에서는 터미널에서 `./run_mac_linux.sh`를 실행해요.

직접 실행하고 싶다면:
```
python -m venv .venv
.venv\Scripts\activate        (Mac/Linux: source .venv/bin/activate)
pip install -r requirements.txt
python app.py
```

## 시연 순서

화면 위쪽의 **사장님 / 학생** 버튼으로 역할을 바꿔 가며 진행해요.

1. 사장님: **의뢰하기**에서 필요한 작업을 말로 적고 **AI로 의뢰서 채우기** → 의뢰 올리기
2. 학생: 프로젝트 목록 → 상세 보기 → **지원하기**
3. 사장님: 지원자 보기 → **AI 적합도 분석** → 학생 선택
4. 학생: 진행 작업 → 초안 이미지 올리기 → 중간 확인 요청
5. 사장님: 피드백 작성 → **AI로 수정 요청 정리해서 보내기**
6. 학생: 수정 항목 체크 → 최종 결과물 제출
7. 사장님: 확인 체크리스트 → 별점·후기 → 완료 확인
8. 학생: 프로필에서 포트폴리오와 실무 기록 확인

**학생 찾기 (사장님)**
- **학생 찾기** 탭에서 이름·학과·작업 종류로 검색하고, 작업 종류·지역·일정으로 걸러 봐요. 북마크로 찜하면 "찜한 학생만"으로 모아 볼 수 있어요.
- **포트폴리오 보기** → 작업물, 함께할 수 있는 작업(가격), 사장님 후기를 확인해요.
- **이 학생에게 의뢰하기**를 누르면 그 학생에게만 보이는 지명 의뢰가 만들어지고, 내 의뢰에서 바로 확정할 수 있어요.
- 같이가게에서 완료한 프로젝트는 학생 포트폴리오의 작업물과 후기에 자동으로 추가돼요.

화면 아래 **예시 데이터로 초기화**를 누르면 처음 상태로 돌아가요.

## 실제 AI(Claude) 연결하기

키가 없어도 모든 기능이 작동해요. 이때 AI 부분은 미리 정해 둔 규칙으로 답해요.

실제 AI를 쓰려면:
1. https://console.anthropic.com 에서 API 키를 발급받아요.
2. `.env.example` 파일을 복사해 이름을 `.env`로 바꾸고 `ANTHROPIC_API_KEY=` 뒤에 키를 붙여 넣어요.
3. 서버를 다시 켜면 화면 아래에 "AI: Claude 연결됨"이 표시돼요.

> `.env` 파일(키)은 다른 사람에게 보내거나 GitHub에 올리지 마세요. `.gitignore`에 이미 빠져 있어요.

## 다른 사람에게 보여주기

- **같은 와이파이에 있는 사람:** 서버를 켜면 검은 창에 `같은 와이파이: http://192.168.x.x:5000` 주소가 나와요. 이 주소를 휴대폰이나 다른 노트북에서 열면 돼요.
  Windows 방화벽 허용 창이 뜨면 "허용"을 눌러 주세요.
- **인터넷의 누구나:** Render(https://render.com) 같은 무료 서버에 올려요.
  1. 이 폴더를 GitHub 저장소로 올려요.
  2. Render에서 New → Web Service → 그 저장소 선택
  3. Build Command: `pip install -r requirements.txt` / Start Command: `gunicorn app:app`
  4. AI를 쓰려면 Environment에 `ANTHROPIC_API_KEY`를 추가해요.
  - 무료 요금제는 서버가 다시 시작될 때 저장된 데이터와 업로드가 지워질 수 있어요. 시연용으로는 충분해요.

## 폴더 구조

```
gachi-gage/
├─ app.py            서버와 API (의뢰, 지원, 선택, 초안, 피드백, 완료)
├─ ai.py             AI 기능 3가지 (의뢰서 작성, 적합도 분석, 피드백 정리)
├─ db.py             SQLite 저장소와 예시 데이터
├─ static/           화면 (index.html, app.js, style.css)
├─ uploads/          올린 이미지가 저장되는 곳
├─ data/             데이터베이스 파일 (처음 실행할 때 생겨요)
├─ requirements.txt  필요한 패키지
├─ run_windows.bat   Windows 실행 파일
└─ .env.example      AI 키 설정 예시
```

## MVP의 한계

- 로그인 대신 역할 전환 버튼을 써요. 학생은 예시 학생 "이서윤"으로 고정돼 있어요.
- 결제와 보수 지급은 화면 문구로만 표시돼요.
- 실서비스로 키우려면 회원가입·로그인, 결제(PG) 연동, 채팅, 알림이 필요해요.
