# 같이가게 — 우리 가게를 이해하는 마케팅 AI

홍보할 필요는 있지만 시간·비용·인력이 부족한 소상공인을 위한 마케팅 AI 앱의 해커톤 MVP예요.
가게 정보를 한 번 정리하면 매주 **누구에게, 무엇을, 언제, 왜** 알릴지 추천하고, 홍보 문구를 준비해 주고,
실행 기록(못 했다면 그 이유)을 다음 주 추천에 반영해요.

## 실행하기 (Windows)
1. Python이 없다면 https://www.python.org/downloads/ 에서 설치해요. 첫 화면에서 **"Add python.exe to PATH"**를 꼭 체크하세요.
2. **`run_windows.bat`**을 더블클릭해요. 처음 한 번은 1~2분 걸리고, 브라우저에서 http://127.0.0.1:5000 이 열려요.
3. 끄려면 검은 창에서 `Ctrl + C`를 누르거나 창을 닫아요.

Mac/Linux는 `./run_mac_linux.sh`를 실행해요.

## 시연 순서 (약 3분)
1. **예시 가게로 둘러보기 → PC방**을 누르거나, **우리 가게 등록하기**로 질문에 하나씩 답해요.
2. **요약** 화면에서 "이번 주 할 일" 카드를 확인해요. 사진 필요 여부, 소요 시간, 채널이 함께 나와요.
3. **자세히 보기**로 추천 근거를 펼치면 **사실 / 지역 정보 / 제안**이 구분돼서 보여요.
4. **홍보 문구 만들기**에서 가게 이름, 가격, 기간을 확인하고 문구를 받아요. 복사하기 → 인스타그램 열기.
   자동으로 올리지 않고 사장님이 확인하고 직접 올려요.
5. **기록하기**에서 "못 했어요 → 사진이 없었어요"를 골라요.
6. **기록** 탭 → **다음 주 추천 받기**(시연용)를 누르면, 요약 화면에
   "지난주에 '사진이 없었어요'라고 하셔서, 이번 주는 사진 없이 할 수 있는 홍보를 먼저 골랐어요"가 나와요.
   → **일반 GPT와 달리 실행 기록이 다음 추천을 바꾸는 장면**이에요.
7. **둘러보기**에서 가게 정보 수정, 우리 동네 소식(출처·기준일), 플랜·사용량을 보여줘요.

방문자(브라우저)마다 가게가 따로 저장돼요. 둘러보기 → 처음부터 다시로 지울 수 있어요.

## 실제 AI(Claude) 연결하기
키가 없어도 모든 기능이 작동해요. 이때 추천과 문구는 미리 정해 둔 규칙으로 만들어요.
1. https://console.anthropic.com 에서 API 키를 발급받아요. 월 사용 한도도 꼭 설정하세요.
2. `.env.example`을 복사해 이름을 `.env`로 바꾸고 `ANTHROPIC_API_KEY=` 뒤에 키를 넣어요.
3. 서버를 다시 켜면 요약 화면 아래에 "AI: Claude 연결됨"이 표시돼요.

> `.env`(키)는 다른 사람에게 보내거나 GitHub에 올리지 마세요. 키는 서버에만 있고 화면 코드에는 들어가지 않아요.

## 발표에서 구분해서 말할 것
| 실제로 작동 | 시연용 데이터·화면 | 향후 계획 |
|---|---|---|
| 질문형 가게 등록과 수정 | 지역 맥락(기말고사, 기온 등) | 공공데이터(상권·행사 일정) 연결 |
| 주간 추천과 근거 표시 | 다음 주 넘기기 버튼 | 실제 주간 알림(카카오 알림톡) |
| 홍보 문구 만들기, 사용량 집계 | 플랜 변경(결제 없음) | 결제, 추가 크레딧 |
| 실행 기록 → 다음 추천 반영 | 예시 가게 3곳 | 리뷰·인사이트 캡처 분석, SNS 자동 업로드 검토 |

## 다른 사람에게 보여주기
- **같은 와이파이:** 서버를 켜면 검은 창에 나오는 `http://192.168.x.x:5000` 주소를 휴대폰에서 열어요.
- **인터넷:** Render에서 Build `pip install -r requirements.txt`, Start `gunicorn app:app`으로 배포해요.
  무료 요금제는 재시작 시 데이터가 지워질 수 있어요.

## 폴더 구조
```
gachi-gage/
├─ app.py        서버와 API (등록, 추천, 문구, 기록, 다음 주, 플랜)
├─ ai.py         AI 기능 (주간 추천, 홍보 문구) + 키가 없을 때 규칙 기반 예시
├─ region.py     지역·시즌 맥락 (시연용 예시 데이터, 출처·기준일 포함)
├─ db.py         SQLite 저장소 (data/gachi.db)
├─ static/       화면 (index.html, app.js, style.css)
├─ requirements.txt · run_windows.bat · run_mac_linux.sh · Procfile · .env.example
```

## MVP의 한계

- 비밀번호 로그인 없이 시작 화면에서 역할만 골라요. 누구나 어느 역할로든 들어갈 수 있어서, 실서비스에서는 회원가입·로그인이 필요해요.
- 학생은 예시 학생 "이서윤"으로 고정돼 있어요.
- 결제와 보수 지급은 화면 문구로만 표시돼요.
- 실서비스로 키우려면 회원가입·로그인, 결제(PG) 연동, 채팅, 알림이 필요해요.

## SNS 마케팅 (sns-marketing/)

사장님이 홍보할 내용과 사진을 넣으면 AI가 문구·홍보 카드·사진 보정을 만들고, 인스타그램·페이스북·스레드에 동시에 올리고 관리하는 기능이에요. Node.js로 따로 실행해요. 실행 방법과 **실제 구현 / 목업 구분**은 [`sns-marketing/README.md`](sns-marketing/README.md)를 보세요.
